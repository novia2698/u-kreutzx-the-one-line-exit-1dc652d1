A program that writes the funniest one-line resignation letter it can: a professional queue-stander who, after nine years, finally reaches the front of the line — and it is the exit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

The line is written to `entry.txt` in the output directory: one line, 127 characters, no trailing newline. It is deterministic — the same line on every run, with no network, no clock, and no randomness.

## The line

> I hereby resign as a professional queue-stander: after nine years I finally reached the front of the line, and it was the exit.
